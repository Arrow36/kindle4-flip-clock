## Original Kindle Clock concept

This project was inspired by [LaisRast/kclock](https://github.com/LaisRast/kclock) by Laith Rastanawi. The public release does not include that repository's SVG template, `rsvg-convert`, `pngcrush`, or bundled dynamic libraries. The current flip-clock renderer, settings system, lunar calendar support, and physical-key controls are implemented in Lua and shell for this edition.
